# Estatua de la Libertad 🗽 — visor 3D (demo)

**En línea:** https://estatua-libertad-3d.vercel.app/

Visor 3D low-poly hecho con **Three.js**. Arrastra para girar, rueda o pellizco
para acercar. Sin backend, sitio 100% estático.

Todo procedural, sin archivos de modelo: pedestal escalonado, túnica de 7 caras
con pliegues, corona de 7 picos en abanico, antorcha dorada con llama emisiva y
tabula en el brazo izquierdo.

## Ver local

```bash
npx serve .
```

## Estructura

```
index.html  css/estilo.css  js/main.js
```
